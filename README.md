# AI-Driven AQI Prediction using XGBoost
### MS Elevate AICTE Internship - Capstone Project

**Author:** Pragadeeswar S.K.  
**Institution:** Panimalar Engineering College  
**Department:** Electrical and Electronics Engineering (EEE)

## Project Overview
This project uses the **XGBoost Regressor** to predict the Air Quality Index (AQI) based on concentrations of pollutants like PM2.5, NO2, and CO. 

## Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, XGBoost, Scikit-Learn, Matplotlib
* **Hardware:** MacBook Air M2 (16GB RAM)

## Results
The model compares actual vs. predicted values using a scatter plot to visualize performance.
